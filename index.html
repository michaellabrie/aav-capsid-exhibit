04 / UNDER THE HOOD

How the network learned.

A reproducible training pipeline, a simple comparison model, and a test set kept out of model training and threshold selection.

INPUT10Numerical + one-hot features
⟶
HIDDEN 0114ReLU units

OUTPUT1Sigmoid probability

Input values are standardized using training-set statistics only. Each hidden layer combines learned weights and biases, then applies ReLU. A sigmoid converts the final score to a value between zero and one. The exported weights, scaler, and browser calculations come from the trained Python model.

01 / DATA

6,000 generated scenarios

All labels come from a randomized simulation with serotype categories, AAP condition, interface and stability indices, pH, ionic strength, and concentration. They are not patient or laboratory observations.

02 / EVALUATION

Train / validate / test

4,200 training, 900 validation, 900 test. The validation split selected the classification threshold. The test split was used only for final reporting and exhibit case examples.

03 / COMPARISON

Better than guessing one class

The neural network is compared with a majority-class baseline from the training split. Test accuracy is informative here, but precision and recall show which mistakes it makes.

04 / LIMITS

Educational, not predictive biology

The synthetic generating rules include assumptions about AAP dependence. Generalization to real capsid experiments, actual serotypes, and wet-lab conditions has not been demonstrated. Correlation is not causal evidence.
